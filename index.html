☁️ Google Диск — Client ID

Вставьте «Идентификатор клиента» OAuth 2.0 из Google Cloud Console. Пошаговая инструкция — в разделе «Синхронизация → ❓ Настройка».

Client ID
❓ Как подключить Google Диск
1. Откройте console.cloud.google.com и создайте новый проект.

2. Включите в нём Google Drive API (APIs & Services → Library → Google Drive API → Enable).

3. Перейдите в APIs & Services → Credentials → Create Credentials → OAuth client ID, тип — Web application.

4. В поле Authorized JavaScript origins укажите адрес, по которому открывается это приложение (например https://username.github.io при использовании GitHub Pages, или http://localhost:8000 для локального сервера). Важно: открытие как локального файла (file://) Google не поддерживает — страницу нужно разместить в интернете или открыть через локальный сервер.

5. Скопируйте Client ID и вставьте его в приложении: «Синхронизация → Подключить».

После этого файлы будут храниться в папке «Мои задания — файлы» на вашем Google Диске и автоматически становятся доступными по ссылке — вы сможете просматривать их на любом устройстве, даже без входа в ваш Google-аккаунт. Удаление файла из задания (или окончательное удаление задания из корзины) удаляет файл из Диска — это работает на устройстве, где выполнен вход в аккаунт-владелец файлов.
